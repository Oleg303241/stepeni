03 / Три главных правила

Смотри на знак между степенями

Умножение ·

Складываем показатели

x2 · x3 = x5

Два множителя и ещё три. Всего пять: 2 + 3 = 5.

Деление :

Вычитаем показатели

x5 : x3 = x2

Три пары множителей сокращаются. Остаются два: 5 − 3 = 2.

Степень в степени

Умножаем показатели

(x2)3 = x6

Три группы по два множителя. Всего шесть: 2 · 3 = 6.

Когда работают правила? При умножении и делении основания должны быть одинаковыми. При делении основание не равно нулю. Для сложения такого правила нет: 23 + 22 = 8 + 4 = 12.

Первая степень

x1 = x

Один множитель — это само число.

Нулевая степень

x0 = 1

Если x ≠ 0: x3 : x3 = 1. Значит, x3−3 = x0 = 1.

Буква — тоже число

a2 · an = a2+n

n — число, которое пока не сообщили. Если n = 3, получим a5.

Почему (−2)³ = −8, а (−2)⁴ = 16?

Два минуса при умножении дают плюс: (−2) · (−2) = 4. Ещё один множитель −2 даёт −8. Ещё один — 16. Чётное число отрицательных множителей даёт плюс, нечётное — минус.

Как вычислить (0,3)³?

0,3 · 0,3 = 0,09. Затем 0,09 · 0,3 = 0,027. В записи 3 · 3 · 3 = 27 нужно отделить три цифры после запятой, потому что у каждого множителя одна цифра после запятой.
