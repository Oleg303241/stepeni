Медиана, минимум, максимум и размах

Медиана — середина упорядоченного ряда. Размах показывает расстояние от самого маленького значения до самого большого.

Твой урок

1. Понять правило2. Разобрать пример3. Попробовать руками4. Проверить себя

10–15 минут без спешки. Можно остановиться и продолжить позже.

01 / Понять

Разберём по шагам

  1. Сначала расположи числа по возрастанию.
  2. При нечётном количестве медиана — центральное число; при чётном — среднее двух центральных.
  3. Размах = максимум − минимум. Не путай медиану со средним арифметическим.
02 / Посмотреть решение

Один пример — все шаги

Данные: 9, 2, 3, 20, 4

Упорядочим: 2, 3, 4, 9, 20. Медиана 4.

Размах 20−2=18. Среднее при этом 38:5=7,6.

Где легко ошибиться
Без упорядочивания нельзя брать «число в середине записи».
03 / Попробовать руками

Измени. Посмотри. Объясни.

Модель помогает увидеть закономерность. В геометрии рисунок сам по себе не заменяет доказательство.

04 / Закрепить

Теперь твоя очередь

Вводи число, десятичную дробь через запятую или точку, либо дробь вида 3/4. Единицы писать не нужно. В заданиях «да/нет» вводи 1 или 0.

1. Медиана чисел 8, 1, 3?

Показать разбор

Ряд 1,3,8: в центре 3. Ответ: 3.

2. Медиана 1, 3, 5, 9?

Показать разбор

Среднее 3 и 5 равно 4. Ответ: 4.

3. Размах чисел −2, 4, 7?

Показать разбор

7−(−2)=9. Ответ: 9.

Ответы и разбор:
  1. 3. Ряд 1,3,8: в центре 3.
  2. 4. Среднее 3 и 5 равно 4.
  3. 9. 7−(−2)=9.
