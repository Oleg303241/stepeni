Алгебра / Тема 18

Линейные уравнения

Уравнение похоже на равновесие весов. Можно одинаково изменить обе чаши, и равенство сохранится.

Твой урок

1. Понять правило2. Разобрать пример3. Попробовать руками4. Проверить себя

10–15 минут без спешки. Можно остановиться и продолжить позже.

01 / Понять

Разберём по шагам

  1. Раскрой скобки и приведи подобные.
  2. Прибавь или вычти одно и то же выражение с обеих сторон. Это объясняет «перенос со сменой знака».
  3. В ax = b при a ≠ 0 раздели обе части на a. Если a = 0: при b = 0 решений бесконечно много, иначе решений нет.
02 / Посмотреть решение

Один пример — все шаги

3x + 5 = 17

Вычитаем 5: 3x = 12. Делим на 3: x = 4.

Проверка: 3·4 + 5 = 17.

Где легко ошибиться
Нельзя делить на коэффициент, не проверив, не равен ли он нулю.
03 / Попробовать руками

Измени. Посмотри. Объясни.

Модель помогает увидеть закономерность. В геометрии рисунок сам по себе не заменяет доказательство.

04 / Закрепить

Теперь твоя очередь

Вводи число, десятичную дробь через запятую или точку, либо дробь вида 3/4. Единицы писать не нужно. В заданиях «да/нет» вводи 1 или 0.

1. 2x + 7 = 19. Найди x.

Показать разбор

2x = 12, x = 6. Ответ: 6.

2. 5(x−1) = 20. Найди x.

Показать разбор

x−1 = 4, x = 5. Ответ: 5.

3. 7−3x = 1. Найди x.

Показать разбор

−3x = −6, x = 2. Ответ: 2.

Ответы и разбор:
  1. 6. 2x = 12, x = 6.
  2. 5. x−1 = 4, x = 5.
  3. 2. −3x = −6, x = 2.
