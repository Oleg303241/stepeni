Алгебра / Тема 22

Линейная функция и прямая пропорциональность

График y = kx+b — прямая. Число b поднимает её, а k задаёт направление и крутизну.

Твой урок

1. Понять правило2. Разобрать пример3. Попробовать руками4. Проверить себя

10–15 минут без спешки. Можно остановиться и продолжить позже.

Сначала познакомимся

Слова и обозначения

≠ — «не равно»
Например, x ≠ 0 означает, что вместо x можно брать допустимые числа, кроме нуля.
01 / Понять

Разберём по шагам

  1. Для построения достаточно двух разных точек. Найди y для двух значений x.
  2. Если k > 0, прямая идёт вверх слева направо; если k < 0 — вниз; если k = 0 — горизонтально.
  3. Прямая пропорциональность y = kx при k ≠ 0 проходит через начало координат. Параллельные разные прямые имеют одинаковые k и разные b.
02 / Посмотреть решение

Один пример — все шаги

Построить y = 2x−1

x=0 → y=−1. x=2 → y=3.

Проведи прямую через (0;−1) и (2;3).

Где легко ошибиться
b — значение y при x=0, а не координата пересечения с осью x.
03 / Попробовать руками

Измени. Посмотри. Объясни.

Модель помогает увидеть закономерность. В геометрии рисунок сам по себе не заменяет доказательство.

04 / Закрепить

Теперь твоя очередь

Вводи число, десятичную дробь через запятую или точку, либо дробь вида 3/4. Единицы писать не нужно. В заданиях «да/нет» вводи 1 или 0.

1. В y = −3x+4 чему равно k?

Показать разбор

k — множитель при x. Ответ: -3.

2. В y = 2x−7 чему равно b?

Показать разбор

Свободное число −7. Ответ: -7.

3. Для y = 4x найди y при x = 3.

Показать разбор

4·3 = 12. Ответ: 12.

Ответы и разбор:
  1. -3. k — множитель при x.
  2. -7. Свободное число −7.
  3. 12. 4·3 = 12.
