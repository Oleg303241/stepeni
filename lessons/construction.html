Геометрия / Тема 43

Построения циркулем и линейкой

Циркуль переносит расстояние, линейка проводит прямую. В классических построениях деления линейки не используют.

Твой урок

1. Понять правило2. Разобрать пример3. Попробовать руками4. Проверить себя

10–15 минут без спешки. Можно остановиться и продолжить позже.

01 / Понять

Разберём по шагам

  1. Серединный перпендикуляр: из обоих концов отрезка проведи дуги одного радиуса, большего половины отрезка; соедини две точки пересечения.
  2. Биссектриса: дуга из вершины пересекает стороны; из полученных точек проведи равные дуги внутри угла. Соедини вершину с их пересечением.
  3. Треугольник по трём сторонам: построй основание; из его концов проведи окружности радиусов двух других сторон; их пересечение — третья вершина. Перенос угла выполняют переносом дуги и хорды между её пересечениями со сторонами.
02 / Посмотреть решение

Один пример — все шаги

Построить треугольник со сторонами 4, 5, 6 см

Построй основание 6 см. Из его концов проведи окружности радиусов 4 и 5 см.

Соедини их точку пересечения с концами основания. Есть два зеркальных положения.

Где легко ошибиться
Перед построением по трём сторонам проверь неравенство треугольника.
03 / Попробовать руками

Измени. Посмотри. Объясни.

Модель помогает увидеть закономерность. В геометрии рисунок сам по себе не заменяет доказательство.

04 / Закрепить

Теперь твоя очередь

Вводи число, десятичную дробь через запятую или точку, либо дробь вида 3/4. Единицы писать не нужно. В заданиях «да/нет» вводи 1 или 0.

1. Отрезок 8 см. Минимальный целый радиус дуг для серединного перпендикуляра?

Показать разбор

Радиус должен быть строго больше 4. Ответ: 5.

2. Биссектриса угла 60°. Половина?

Показать разбор

60:2=30. Ответ: 30.

3. Можно построить невырожденный треугольник 2, 3, 5? 1 — да, 0 — нет.

Показать разбор

2+3=5: вершины лежат на одной прямой. Ответ: 0.

Ответы и разбор:
  1. 5. Радиус должен быть строго больше 4.
  2. 30. 60:2=30.
  3. 0. 2+3=5: вершины лежат на одной прямой.
