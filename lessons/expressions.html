Алгебра / Тема 09

Буквенные выражения и подстановка

Буква — место для числа. Формула работает как рецепт: подставь значение и выполни действия.

Твой урок

1. Понять правило2. Разобрать пример3. Попробовать руками4. Проверить себя

10–15 минут без спешки. Можно остановиться и продолжить позже.

Сначала познакомимся

Слова и обозначения

≠ — «не равно»
Например, x ≠ 0 означает, что вместо x можно брать допустимые числа, кроме нуля.
01 / Понять

Разберём по шагам

  1. Сначала запиши значение каждой буквы. Отрицательные числа подставляй в скобках.
  2. Соблюдай порядок: скобки, степени, умножение и деление, затем сложение и вычитание.
  3. Выражение 1/(x−2) имеет смысл только при x ≠ 2: знаменатель не должен быть нулём.
02 / Посмотреть решение

Один пример — все шаги

3x² − 2 при x = −2

3 · (−2)² − 2 = 3 · 4 − 2.

12 − 2 = 10.

Где легко ошибиться
−2² = −4, а (−2)² = 4. Скобки меняют основание степени.
03 / Попробовать руками

Измени. Посмотри. Объясни.

Модель помогает увидеть закономерность. В геометрии рисунок сам по себе не заменяет доказательство.

04 / Закрепить

Теперь твоя очередь

Вводи число, десятичную дробь через запятую или точку, либо дробь вида 3/4. Единицы писать не нужно. В заданиях «да/нет» вводи 1 или 0.

1. 2x + 3 при x = 4.

Показать разбор

2 · 4 + 3 = 11. Ответ: 11.

2. x² при x = −3.

Показать разбор

(−3) · (−3) = 9. Ответ: 9.

3. 5(a − 1) при a = 3.

Показать разбор

Сначала 3 − 1 = 2, затем 5 · 2 = 10. Ответ: 10.

Ответы и разбор:
  1. 11. 2 · 4 + 3 = 11.
  2. 9. (−3) · (−3) = 9.
  3. 10. Сначала 3 − 1 = 2, затем 5 · 2 = 10.
