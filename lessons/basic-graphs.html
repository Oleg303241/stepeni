Алгебра / Тема 23

Графики модуля, квадрата и куба

Разные правила рисуют разные линии. Таблица из нескольких точек помогает увидеть форму, но не заменяет точную формулу.

Твой урок

1. Понять правило2. Разобрать пример3. Попробовать руками4. Проверить себя

10–15 минут без спешки. Можно остановиться и продолжить позже.

01 / Понять

Разберём по шагам

  1. График y=|x| похож на букву V. При x ≥ 0 имеем y=x, при x<0 имеем y=−x. Значения неотрицательны.
  2. График y=x² — парабола: числа x и −x дают одинаковый квадрат. График симметричен относительно оси y.
  3. Для y=x³ знак y совпадает со знаком x. График проходит через (−1;−1), (0;0), (1;1). Квадрат и куб в некоторых учебниках изучают позже; здесь это дополнительное знакомство.
02 / Посмотреть решение

Один пример — все шаги

Сравним три функции при x=−2

|−2|=2; (−2)²=4; (−2)³=−8.

Один и тот же вход дал разные выходы, потому что правила разные.

Где легко ошибиться
В y=x² отрицательное x даёт положительное y. В y=x³ отрицательное x даёт отрицательное y.
03 / Попробовать руками

Измени. Посмотри. Объясни.

Модель помогает увидеть закономерность. В геометрии рисунок сам по себе не заменяет доказательство.

04 / Закрепить

Теперь твоя очередь

Вводи число, десятичную дробь через запятую или точку, либо дробь вида 3/4. Единицы писать не нужно. В заданиях «да/нет» вводи 1 или 0.

1. y=|x| при x=−4. Найди y.

Показать разбор

Модуль −4 равен 4. Ответ: 4.

2. y=x² при x=−3. Найди y.

Показать разбор

(−3)²=9. Ответ: 9.

3. y=x³ при x=−2. Найди y.

Показать разбор

(−2)³=−8. Ответ: -8.

Ответы и разбор:
  1. 4. Модуль −4 равен 4.
  2. 9. (−3)²=9.
  3. -8. (−2)³=−8.
